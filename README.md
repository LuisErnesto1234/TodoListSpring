# 📝 To-Do List con Spring Boot

## 📌 Descripción
Este es un proyecto **To-Do List** desarrollado con **Spring Boot, Thymeleaf y Tailwind CSS**, que permite gestionar tareas de manera sencilla. Los usuarios pueden **agregar, editar y eliminar tareas**, además de asignarles un estado.

---

## 🚀 Tecnologías Utilizadas
- **Spring Boot** - Framework backend en Java
- **Thymeleaf** - Motor de plantillas para las vistas
- **Spring MVC** - Para manejar las peticiones HTTP
- **Tailwind CSS** - Para estilos modernos y responsivos
---

## 📥 Instalación y Configuración

### 🔹 1. Clona el repositorio
```bash
git clone https://github.com/TU-USUARIO/todo-list-spring.git
cd todo-list-spring
```
